Project Overview

From customer artwork to cut-ready geometry.

Adcut needs a dependable local tool for converting customer logos into 2D CAD drawings used in water jet cutting. The key challenge is preserving color boundaries as separate, closed vector paths because each logo color represents a different flooring or turf material.

The target users are internal Adcut operators and CNC programmers who prepare files for water jet cutting. The project focuses on an open-source stack that can run on Windows without cloud processing, while still giving operators enough review and adjustment controls before export.

Workflow

Five steps from upload to fabrication file.

01

Upload Image

Accept common customer file formats including JPEG, PNG, WEBP, GIF, and PDF.

02

Color Reduction

Group similar colors into manageable material channels while preserving important logo features.

03

Vectorization

Trace each color channel into closed paths suitable for downstream CAD handling.

04

Review and Tweak

Let users inspect boundaries, adjust simplification, and confirm that paths are watertight.

05

Export

Produce SVG and DXF files, including R12/R2000 DXF compatibility targets.

Technical Design

An open-source local pipeline built for operator control.

Proposed Application Layer

Streamlit provides a fast Python-first path for a local prototype, while React or Vue can support a more customized desktop-style interface if the project shifts toward a richer front end.

Image Processing

OpenCV handles preprocessing, color clustering, cleanup, contour detection, and preview generation.

Vector Tracing

Potrace or vtracer can convert separated regions into smooth vector paths for each material color.

CAD Export

ezdxf supports DXF generation, with SVG output available for inspection and interchange.

Packaging

Docker can stabilize development environments; PyInstaller can package a Windows-friendly local tool.

Read the D1 specifications draft and open questions

Functional Requirements

  • Accept JPEG, PNG, WEBP, GIF, and PDF artwork files.
  • Allow configurable color reduction to match logo colors to material zones.
  • Generate accurate closed paths along color boundaries without gaps or overlaps.
  • Export standard SVG and R12/R2000 compliant DXF files for CNC preparation.

Non-Functional Requirements

  • Run locally on an operator's Windows machine.
  • Confirm with the client whether fully offline operation and restrictions on external services are required.
  • Use open-source, commercially viable tools with no recurring licensing fees.
  • Provide a straightforward interface for non-software engineers.
