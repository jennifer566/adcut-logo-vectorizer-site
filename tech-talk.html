Image Vectorization

A 20-minute tutorial explaining how raster artwork becomes scalable SVG paths and CAD geometry. Every Team E member participates in preparation and delivery.

Repeat the demonstration

  1. Install uv, clone the development repository, and open a terminal in the repository.
  2. Run uv sync --locked --dev to create the locked environment.
  3. Run uv run streamlit run app.py and open http://localhost:8501.
  4. Upload examples/holes-and-curves.png.
  5. Set output width to 10 inches, maximum colors to 4, curve simplification to 1.5 pixels, and keep the dominant border color ignored.
  6. Compare the raster source with the SVG curve preview. Record color-region, closed-path, and curve-segment counts.
  7. Download both SVG and DXF. Open the SVG in a browser and inspect its path data in a text editor.
  8. Inspect DXF entities with uv run python -c "import ezdxf; d=ezdxf.readfile('adcut-vectorized.dxf'); print([(e.dxftype(), e.dxf.layer) for e in d.modelspace()])".
  9. Explain that successful serialization does not establish fabrication readiness. Scale, topology, CAD import, and client acceptance still require validation.

Demo fallback

If the live application cannot start, use the three repository samples and the deck's captured outputs. Walk through the same controls, show the SVG path commands, and use the automated test results as evidence. Do not substitute unverified customer artwork.
