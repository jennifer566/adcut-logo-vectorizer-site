D4 / Initial Operator Guide

User Manual

Status: Development-build instructions, updated October 26, 2026. Exported files require CAD inspection and client approval before fabrication.

What the application does

The application runs locally and converts JPEG, PNG, WEBP, the first GIF frame, or the first PDF page into closed color-region paths. It previews SVG curves and downloads SVG and DXF R2000 files. The current build does not guarantee exact circles, shared-edge removal, machine compatibility, or a fabrication-ready result.

Install and start

  1. Install uv and Git.
  2. Clone the development repository.
  3. Open a terminal in the repository folder and run uv sync --locked --dev.
  4. Run uv run streamlit run app.py.
  5. Open the local address printed in the terminal, normally http://localhost:8501.

Installation needs internet access to obtain dependencies. Normal processing remains on the computer and does not require a hosted service.

Convert artwork

  1. Choose an Output width greater than zero and select inches or millimeters.
  2. Choose the maximum number of colors. Start with the visible material colors in the logo, then compare the preview.
  3. Set curve simplification. Lower values retain more detail; higher values may reduce control points and remove detail.
  4. Leave Ignore the dominant border color enabled when a uniform outer background should not become a material region.
  5. Select the artwork with Choose artwork. For a first test, use a file in the repository's examples folder.
  6. Compare the source and SVG preview. Read every warning and check the region, path, curve, width, and height metrics.
  7. Download SVG for visual/path inspection and DXF for downstream CAD inspection.

Review before use

  • Confirm that every intended material color is separate and unwanted background is absent.
  • Check that holes remain holes and all required boundaries are closed.
  • Look for missing details, duplicate shared edges, jagged boundaries, and excessive curve complexity.
  • Confirm the physical dimensions and units after import into the target CAD software.
  • Inspect layer names and native entity types. The current DXF uses R2000 because native spline output is not supported in R12.
  • Do not send an output to cutting equipment until the client-approved CAD and physical validation steps pass.

Troubleshooting

ProblemAction
The file cannot be decodedConfirm the extension matches the content, try a supported format, and use a non-corrupt export.
Too many or too few regionsAdjust maximum colors; simplify gradients or photographs before tracing.
Important detail disappearsLower curve simplification and use a higher-resolution source.
Background appears as a regionEnable dominant-border removal or prepare a transparent/uniform background.
SVG preview failsRefresh after the latest code is installed; preserve the error text and input details in a GitHub issue.
CAD scale or geometry is wrongStop before cutting, record units/software version/settings, and report the file and reproduction steps.

Get help and report a defect

Use the development repository's Issues page. Include the application revision, operating system, Python version, input type, settings, expected result, actual result, and a permitted sample or minimal reproduction. Do not attach confidential customer artwork without permission.
